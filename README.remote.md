# Valore 24 AI Office - SmartMail Hub

Modulo WordPress nativo PHP per gestione email, contatti, calendario e predisposizione AI della piattaforma Valore 24 AI Office.

## Stato

MVP tecnico in sviluppo.

## Funzioni incluse

- Plugin installabile.
- Tabelle database dedicate.
- Capability WordPress.
- Account IMAP/SMTP con credenziali cifrate.
- Client IMAP/SMTP.
- REST API.
- Inbox base.
- Rubrica locale.
- Calendario locale base.
- Log e audit.
- Predisposizione AI.

## Note sicurezza

Non salvare mai credenziali in chiaro. Non inserire password reali in repository o documenti di consegna.
